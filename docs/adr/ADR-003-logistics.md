# ADR-003: Exactly one physical logistics model

- **Status:** Accepted, Tested.
- **Decision:** only **Data** is carried by hand, from wells to the Core or a Data Cache. Code, Hash, Compute and Memory are global. Operators are staffed automatically, and trainees are pulled from free Runners.
- **Why:** physical Data flow gives raids something visible to cut and makes the city look alive. Keeping everything else global avoids the micromanagement that critics flagged in *Stronghold Legends* (RESEARCH #4).
- **Rejected for now:** Code carriers to each building, conduit networks (interpretation C), heat and bandwidth. These are in the backlog as optional depth, and each has to show a distinct decision before it's added.
